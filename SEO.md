# SEO Оптимизация WANEX

## ✅ Реализованные улучшения

### 1. Мета-теги и метаданные

- ✅ **Основные мета-теги:**
  - Title (до 60 символов)
  - Meta Description (до 160 символов)
  - Keywords (релевантные ключевые слова)
  - Author и Language

- ✅ **Open Graph теги** для социальных сетей:
  - og:title, og:description, og:image
  - og:type, og:url
  - Размеры: 1200x630px

- ✅ **Twitter Card теги:**
  - twitter:card, twitter:title, twitter:description
  - Для улучшения шеринга в Twitter/X

### 2. Структурированные данные (Schema.org)

- ✅ **JSON-LD для LocalBusiness:**
  - name, description, url
  - telephone, email
  - address, geo-координаты
  - priceRange
  - aggregateRating

### 3. Поисковое индексирование

- ✅ **robots.txt:**
  - Позволяет индексирование основного контента
  - Запрещает индексирование админ разделов
  - Указывает на sitemap.xml
  - Управление сheduler ботов (Crawl-delay)

- ✅ **sitemap.xml:**
  - Ссылки на все основные страницы/якоря
  - Указание последних обновлений (lastmod)
  - Приоритеты для каждой страницы
  - Поддержка мобильных сайтов

- ✅ **Canonical URL:**
  - Указывает на главную версию страницы
  - Предотвращает duplicate content

### 4. Мобильная оптимизация

- ✅ **Responsive Design:**
  - Meta viewport для правильного отображения
  - CSS Grid и Flexbox
  - Mobile-first подход

- ✅ **Mobile Performance:**
  - Оптимизация изображений
  - Минификация CSS/JS
  - Удаление console.log в production

### 5. Производительность

- ✅ **Загрузка ресурсов:**
  - Preconnect к Google Fonts
  - Preload критических ресурсов
  - Асинхронная загрузка scripts

- ✅ **Оптимизация сборки:**
  - Terser для минификации JS
  - CSS минификация
  - Sourcemap отключены в production
  - Drop console в production

### 6. Доступность (Accessibility)

- ✅ **Семантический HTML:**
  - Правильная иерархия заголовков
  - Semantic sections (header, main, footer)
  - aria-labels где необходимо

- ✅ **Контрастность:**
  - Цвета соответствуют WCAG AA
  - Читаемый шрифт (Plus Jakarta Sans)
